# Source provenance

This is the auditable reuse ledger for the port. Update it whenever code, constants,
tests, documentation, or generated tables are brought in from another project.
`Reviewed` means behavior or architecture was studied; `rewritten` means new C99 code
implements that behavior; `translated` means a data table or algorithm closely follows
the named source; `copied` means content is substantially verbatim.

## Original copyrighted data

No `RESOURCE.MAP`, `RESOURCE.001`, `SCRANTIC.SCR`, artwork, animation, music, or sound
sample is committed. Tests construct synthetic fixtures or require the user to pass a
path to their own original data. The extracted route table stores behavioral routing
choices, not executable code or media bytes; its upstream extraction and GPL lineage
are nevertheless recorded above.

## Rules for future imports

1. Record repository URL, immutable revision, license, exact source paths, and author.
2. Preserve upstream copyright/license blocks on copied files.
3. Put `SPDX-License-Identifier: GPL-3.0-or-later` on new project source files.
4. State whether material was copied, translated, rewritten from behavior, or merely
   reviewed.
5. Never commit original Sierra/Dynamix content.
